# Capture a learning note

Search the relevant topic directory for the concept and its common aliases. Read the closest entry before choosing a file. For example, a new observation about Linux routes may fit in `networking/02-linux-networking/basic-commands/ip.md`.

Frame the entry around the question the author wanted answered. Give the shortest explanation that answers it, followed by a concrete example when one helps. Preserve the author's own observations and open questions. Attribute ideas from reading to the supplied chapter, article, or link.

When a related note already explains a prerequisite, link to it with a relative path. Check each new local link from the edited file's directory.
